* GPL-3.0-only — скрипты, overlay, рецепты этого репозитория (SPDX в каждом файле).
* DroidDeck (GPL-3.0) — переиспользуются патчи gamescope и layout runtime
  (`droiddeck-ref/` — reference clone, не является частью сборки; удалите перед
  публикацией артефактов).
* Mesa/Turnip — MIT; FEXCore — GPLv2+; Gamescope — BSD-2-Clause; Wine WoW64 — LGPL.
* Steam/Proton — бинарные редистрибутивы Valve, распространяются отдельно от этого
  репозитория (рецепты скачивают официальные зеркала, хеши в checksums/).

  в git не попадают.
